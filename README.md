Pokémon Search


This small, friendly React app lets you look up Pokémon by name and view their base stats. Data comes straight from the public PokéAPI and stats are shown with a simple, readable chart.

Getting started

Prerequisites

- Node.js (version 16 or newer is recommended)

Installation

1. Clone the repository and change into the project folder


2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

No API key required

You can use the app right away—no API key or authentication is necessary because it queries the public PokéAPI.

Built with

- React
- Vite
- PokéAPI
- axios
- recharts
